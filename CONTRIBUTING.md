# Contributing to Veritas Wiki

This wiki is the working source-of-truth document set for Veritas Development Group LLC. External use of company material requires sponsor confirmation.

## How to add content

1. **Profile updates** — confirm with sponsor first; site extraction is automated weekly
2. **Market intelligence** — automated via RMI service; manual additions via PR
3. **Investor profiles** — confirm any pitch material with sponsor before publishing
4. **Reports** — auto-generated via the RMI service; do not edit manually

## Edit conventions

- One PR per logical change
- Cite sources in-line (URL + date)
- Use ISO date format (2026-08-16)
- Preserve chronology in news/activity logs
- Avoid tool/engine references in client-facing material
- Use real source names only (Reddit, Facebook, KC Star, KCTV5, etc.)

## Issue templates

- Use `Idea` for new wiki sections or improvements
- Use `Market Signal` to flag a new development pipeline item, capital partner, or community signal

## Review

- Major profile changes require sponsor sign-off (David Poole)
- Market + community intelligence is reviewed weekly by the RMI service owner (KlickSmartAI / GPC Development)

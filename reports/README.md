## Report Cadence

- **Baseline:** Run once at engagement start
- **Trend:** Weekly / monthly recurring runs
- **Trigger:** Event-driven (capital-raise launches, project updates, material sentiment shifts)

## Categories Captured

1. **Reputation Risk** — name-collision, negative press, completeness of public profile
2. **Customer Sentiment** — reviews, testimonials, complaints
3. **Competitor Signals** — competitive landscape, pipeline overlap
4. **Market Opportunities** — pipeline convergence, capital partner fit, community alignment

## Source Materials

All content in these reports is sourced from publicly available data:
- Company website (extracted via Jina Reader)
- Public news (KCTV5, KC Star, KSHB, Hoodline, BizJournals)
- Public LinkedIn posts (capital partners)
- Public municipal records (Legistar, CityView, Citizen Portal)
- Reddit / Facebook groups / Instagram (community sentiment)

No tool-name leakage (Serper/Tavily/Exa/Hermes references removed from client-facing versions).
